## Architecture — the patterns that are load-bearing here

- **Environment is parsed at startup.** Client variables in `src/lib/env.ts`; server
  variables in `src/lib/server-env.ts`, which imports `server-only` — the Discord webhook URL
  must never reach a client bundle, or anyone can post to the channel
- **The contact form submits through a Server Action**, validated with zod on the server
  before anything is sent to Discord. Client validation is a courtesy, not a control (§FORMS)

## Things to avoid

- **Running `npx` or `npm` from Git Bash after a `cd`** — the owner's `fnm` shell hook is not
  set up for Git Bash, and fails with "Could not determine Node.js install directory". Run
  from the project root without `cd`, or use absolute paths
- **Scaffolding or installing into the scratchpad path** — it exceeds Windows' path length
  (`ENAMETOOLONG`)
- **Accepting `shadcn init` or `add` without reading the diff** — it re-points our colour and
  radius tokens and forces a white page (`decisions.md`, 2026-11-06)
