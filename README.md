# tanveersingh

Tanveer Singh's portfolio site — Next.js App Router, TypeScript, Tailwind v4, deployed on Vercel.

Rebuilt from scratch in November 2026 on the fleet standard. The previous site lives in git
history on `master` (before the `rebuild` branch merges).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Agents and contributors: start with [`CLAUDE.md`](./CLAUDE.md).
