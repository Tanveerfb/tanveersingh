## Work

- **Heading:** 第1話 · Chapter one
- **Title:** The work
- **Tabs (new):** All · Nobility Care Australia · Tinker Together

### Nobility Care Australia

**NCA public website**
Sixteen service pages for an NDIS provider, in light, dark and high-contrast themes. A contrast
audit fails the build on any WCAG AA failure, and an admin area runs the blog, news, FAQs, reviews,
SIL vacancies and team.
Next.js 16 · TypeScript · Tailwind v4 · SCSS · Firebase · next-intl · Leaflet · Vercel
[nobilitycare.com.au](https://www.nobilitycare.com.au)

**NCA learning platform**
Staff training with block-based module authoring, learning paths by department, a compliance
dashboard with escalations and an append-only audit log, certificates and Word import. First working
version in under a week.
Next.js 16 · Tiptap · Firebase · shadcn/ui · Zustand · Zod
[learning.nobilitycare.com.au](https://learning.nobilitycare.com.au)

**NCA staff portal**
Folder-based document storage, view-only documents that can't be downloaded, user provisioning by
invite, and a download and activity log. Internal.
React · Firebase · React Bootstrap · Chart.js

**NCA Links Hub**
A staff forms directory behind Microsoft Entra sign-in, limited to company accounts, with favourites.
Internal.
Next.js 16 · Firebase · shadcn · Zustand

**Microsoft 365 automation**
SharePoint sites for the Supported Independent Living houses, data collection in Microsoft Forms, and
Power Automate flows. Internal.
SharePoint · Forms · Power Automate

### Tinker Together

**Tinker Together website**
The studio's site: portfolio, a blog with scheduled publishing and its own admin, and a website brief
wizard for new clients.
Next.js 16 · Firebase · Vercel
[tinkertogether.studio](https://tinkertogether.studio)

**Toll**
A turn-based 3v3 team card battler for Windows, now in public beta: a shared hand of merging skill
cards, 12 characters, online saves, a self-updating launcher with SHA-256 checks and rollback, and
more than 500 automated tests. Its character art comes from my own pipeline on ComfyUI, running
locally.
Godot 4.7 · GDScript · Firebase · Python · ComfyUI
[Public beta](https://github.com/Tanveerfb/toll-beta/releases/latest) ·
[Project page](https://tinkertogether.studio/portfolio/toll)

**Truqorun website**
Site for an India-based agency with partners in India and Australia: a network map, enquiries to
Firestore and Discord, and an admin leads list.
Next.js 16 · TypeScript · Tailwind v4 · Firebase
[truqorun.com](https://truqorun.com)

**Phasmo Tourney**
Archive and live scoring for a five-tournament Phasmophobia series, each tournament in its own
format.
Next.js · Firebase · React Query · D3 · Chart.js
[phasmo-tourney.vercel.app](https://phasmo-tourney.vercel.app)

**SimetrixDT website**
Site for a digital twin, simulation, SCADA and cybersecurity firm in Parramatta, with an admin CMS
for news, use cases and PDF documentation, and a Three.js background.
Next.js · Firebase · Three.js
[simetrixdt.com](https://www.simetrixdt.com)
