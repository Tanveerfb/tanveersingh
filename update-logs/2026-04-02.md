## Firebase Console — Required Setup

1. **Authentication → Sign-in method** → enable **Email/Password** and **Google**
2. Create admin user manually under Authentication → Users
3. Add your deployment domain to **Authorised Domains**
4. Ensure `firestore-send-email` extension is configured with `NEXT_PUBLIC_CONTACT_EMAIL` as the destination
